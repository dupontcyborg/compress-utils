# compress-utils through each binding, against the C core

Every binding drives the same C core, so compression ratio is byte-identical across languages and only speed differs; this page measures what each binding costs, as the binding's speed divided by the C core's speed.

Each cell is the geometric mean over the levels both were measured at (ten levels; Bun measured levels 1, 6 and 10) of binding speed over C core speed, at the same level on the same machine, so 1.00 is parity and 0.80 means the binding runs at 80% of the C core. **Bold** cells are more than 10% from the C core in either direction; one sample per cell means gaps under about 10% are noise. `-` means the binding does not offer the format (Go has no raw deflate) or the cell was not run.
